# Module 1.2: Utilizing SSH for Remote Access

## 1. What is SSH?
Secure Shell (SSH) is a cryptographic network protocol used to securely access and manage a remote computer's terminal over an unsecured network. 

* **Default Port:** SSH operates on **TCP port 22** by default. 
* **Enumeration:** During the reconnaissance phase, if an `nmap` scan reveals that port 22 is open, the SSH service is active, indicating a potential entry point if credentials are recovered.

## 2. Authentication Methods
To establish an SSH connection, a penetration tester typically leverages one of two methods after initial enumeration:

### A. Cleartext Credentials
If a username and password pair is discovered within local files, scripts, or databases, you can authenticate directly via the terminal:
```bash
ssh Bob@10.10.10.10
```

### B. Private Key Authentication (id_rsa)
If an SSH private key file (typically named `id_rsa`) is exfiltrated from the target system, it can be used to log in without a password. 
*Note: Secure permissions must be applied to the key file prior to connection, or the SSH client will reject it.*
```bash
# Restrict file permissions (Required by Linux)
chmod 600 id_rsa

# Authenticate using the private key
ssh Bob@10.10.10.10 -i id_rsa
```

## 3. Post-Exploitation Advantages of SSH
When executing an assessment on Hack The Box or a real-world infrastructure, upgrading an initial access vector to an SSH session is a priority. 

* **Shell Stability:** Initial access web vulnerabilities usually grant a **Reverse Shell**, which is unstable and will terminate instantly on accidental keystrokes (like `Ctrl+C`). SSH provides a persistent, native administrative session supporting tab-completion and interactive shortcuts.
* **Network Pivoting (Jump Host):** A compromised SSH session allows the operator to use the target machine as a "trampoline" (Jump Host) to route traffic, scan, and launch attacks against internal network segments that are completely isolated from the external internet.

**Summary:** Utilizing SSH is the most stable, secure, and professional method to maintain persistence and execute post-exploitation maneuvers once credentials or keys are acquired.
